# APEX TASK CONTROL — прототип v0.1

Локальное приложение Windows на Python / PySide6 / SQLite.

## Запуск
Установите Python 3.11+ с python.org (галочка Add Python to PATH), распакуйте архив и запустите `start_windows.bat`. Первый запуск установит PySide6 через pip (нужен интернет). После установки программа работает локально без сети.

## Уже реализовано
- Полноэкранное окно с тёмной темой.
- Доски и колонки; карточки с описанием, чек-листом и временем напоминания.
- Перенос карточки в другую колонку через кнопку.
- Блокнот с папками и записями.
- SQLite-хранилище в `%USERPROFILE%\.apex_task_control\apex.db`.
- Уведомления Windows о наступлении срока (однократные).

## Ограничения v0.1
Нет импорта Trello, drag-and-drop, повторных напоминаний, вложений, экспорта, удаления объектов, полнотекстового поиска и автозапуска. Блокнот сохраняется по кнопке, а не автоматически. Это начальный прототип, не полный аналог Trello. Для критически важных рабочих данных пока используйте резервные копии базы.
