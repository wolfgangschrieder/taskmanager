# APEX // TASK CONTROL

Минималистичный локальный менеджер задач и заметок для Windows. Без Trello API, Telegram и облачных аккаунтов.

## Запуск

1. Установите Python 3.11+.
2. Скачайте ZIP репозитория (Code → Download ZIP), распакуйте.
3. Запустите `start_windows.bat`.

## Возможности текущей версии

- Несколько досок, колонки, карточки с описаниями, чек-листами и сроками.
- **Перетаскивание карточек** внутри колонок и между колонками.
- Двойной щелчок открывает карточку; правая кнопка мыши — открыть или удалить с подтверждением.
- Отдельный блокнот с папками, **автосохранением** после паузы ввода.
- `Ctrl+N` создаёт карточку в первой колонке текущей доски.
- Однократные уведомления о сроке, пока приложение запущено.
- Автоматический снимок SQLite при первом запуске за день: `%USERPROFILE%\.apex_task_control\backups\`.
- Данные: `%USERPROFILE%\.apex_task_control\apex.db`. Обновление исходников не удаляет базу.

## Важно

Это развивающийся прототип, не полная замена Trello. Пока отсутствуют импорт, вложения, полноценное удаление/переименование досок, повторные напоминания, поиск и установщик EXE. Системные уведомления могут зависеть от настроек Windows. Перед использованием для критически важных рабочих записей проверьте создание и восстановление резервных копий.

При запуске из скачанного ZIP обновления требуют скачать новый архив; Git не обязателен.

## Расписание и таймеры колонок

В каждой карточке можно установить дату и время напоминания. В меню заголовка колонки можно отключить или включить контроль таймеров. Отключённые колонки не участвуют в расписании и не отправляют уведомления, но сроки карточек сохраняются.

Вкладка **Расписание** собирает задачи из всех досок: просроченные, сегодня, завтра и послезавтра. Задачи отсортированы по сроку, карточки открываются нажатием. Расписание обновляется каждые 30 секунд. Уведомления пока однократные и работают при запущенном приложении; это не секундомер и не повторяющийся будильник.

## Оформление

В разделе «Доски» нажмите **Настройки вида**: можно выбрать одну из четырёх тем, акцентный цвет, шрифт и размер текста. Настройки хранятся в `%USERPROFILE%\\.apex_task_control\\settings.json`.

В редакторе карточки доступны спокойные цветовые метки без эмодзи; выбранный цвет отображается на самой карточке. Срок виден непосредственно под названием задачи. При создании новой карточки срок по умолчанию — через 2 часа, напоминание включено. Для конкретной карточки срок можно отключить.
